# Java关键字和保留字

## Java关键字

> Java关键字是Java中预定义的保留字，具有特定语法共呢个，不能作为变量名、方法名、类名、包名或者参数等标识符使用。关键字用于生命数据类型、控制程序结构或定义访问权限，对编译器具有特殊含义。
